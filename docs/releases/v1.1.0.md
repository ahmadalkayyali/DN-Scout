# DN Scout v1.1.0

v1.1.0 is the publication-ready release of **DN Scout**. This first public release introduces the DN Scout name to communicate the broader CUCM dial-plan analysis capabilities beyond simple extension lookup. It also adds Calling Search Space awareness.

## Highlights

- Optional **Target CSS** scope across each selected cluster.
- New **CSS Scope** tab showing the selected CSS's partition membership/order.
- Correct HTTP 503 handling with retry/backoff; 503 no longer changes the requested AXL schema.
- `AXLDiag --public` mode for safer GitHub/Cisco Community troubleshooting attachments.
- Stronger production TLS guidance and accurate Windows DPAPI credential wording.
- Correct Python minimum version (3.10+) and read-only AXL role prerequisites.
- Release SHA-256 checksums and third-party notices.
- 23 offline tests.

## Important CSS note

CSS-aware mode answers whether a collected route-plan object resides in a partition reachable through the selected CSS. It is not a full implementation of CUCM Digit Analysis and does not model every routing feature or composed line/device CSS behavior.

## Validation status

The v1.1.0 application, including Target CSS discovery and CSS-aware analysis, has been live-validated against CUCM 12.5 and 14 environments. Other releases remain unvalidated until tested.
